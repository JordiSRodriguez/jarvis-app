Política de privacidad de JARVIS

Última actualización: 10 de noviembre de 2026

Quién la usa

JARVIS es un asistente de uso personal. Solo lo usa su propietario, con su propia cuenta de Google. No hay otros usuarios.

Qué datos de Google usa

  • Gmail (solo lectura y etiquetas): para resumir correos y marcar los ya revisados.
  • Google Calendar: para leer la agenda y crear eventos que el propietario aprueba.

Dónde se guardan

Los datos se procesan en un servidor privado del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de tu cuenta de Google.
